## Running an exercise

Most folders are self-contained console projects. If a folder includes a `.csproj` file:

```bash
cd "01 - Call methods from the .NET Class Library using C#"
dotnet run
```

Folder names include spaces and punctuation, so keep them quoted when using `cd` in a terminal.
